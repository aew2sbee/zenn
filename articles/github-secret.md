## 🌱 はじめに

GitHub Actions の secrets は、ログに出力すると `***` にマスクされます。
そのため、「secrets に正しい値が設定されているか」をログで確認できずに困ることがあります。

この記事では、**secrets が正しく設定されているかを確認する方法**を解説します。
野村友規『GitHub CI/CD実践ガイド』（技術評論社）を参考にしながら調査しました。

@[card](https://gihyo.jp/book/2024/978-4-297-14173-8)

:::message alert
**secrets の値をログに出力すると、漏えいにつながります。**

- パブリックリポジトリでは、Actions のログを誰でも閲覧できます。
- ログは保持期間のあいだ残り、ワークフローのコードを削除しても消えません。
- 本番の値を出力してしまった場合は、該当の実行ログを削除し、secrets を再発行（ローテーション）してください。

まずは、値そのものを出力しない方法で確認してください。
:::

## 🌱 結論

:::message
値そのものではなく、**ハッシュ値や文字数**をログに出力し、手元で計算した値と比べて確認します。
:::

```diff yaml
--- 略 ---
    env:
      SECRET_INFO: ${{ secrets.SECRET_INFO }}
    steps:
+      # 値そのものではなく、ハッシュ値と文字数を出力する
+      - run: |
+          echo -n "$SECRET_INFO" | sha256sum
+          echo "${#SECRET_INFO}"
--- 略 ---
```

手元でも同じ値のハッシュ値を計算し、一致すれば正しく設定されています。

```bash
echo -n "設定したはずの値" | sha256sum
```

## 🌱 補足: 値そのものを出力する方法（検証用のダミー値のみ）

どうしても値そのものを確認したい場合の方法です。
**本物の secrets では実行せず、検証用に登録したダミー値でのみ試してください。**

### 1. 検証用の secrets を設定する

今回は検証のため、secrets（`SECRET_INFO`）にダミー値の `ABCDEFG` を設定します。

```text
ABCDEFG
```

### 2. YAML ファイルに `echo` を追加する

bash を使うランナー（`ubuntu-latest` など）を前提としています。

```diff yaml
--- 略 ---
    env:
      SECRET_INFO: ${{ secrets.SECRET_INFO }}
    steps:
+      # 検証用のダミー値でのみ使用し、確認後すぐに削除する
+      - run: echo "${SECRET_INFO:0:1} ${SECRET_INFO#?}"
--- 略 ---
```

- `${SECRET_INFO:0:1}`: 0 文字目から 1 文字を取り出す
- `${SECRET_INFO#?}`: 先頭の 1 文字を取り除いた残りを取り出す

### 3. GitHub Actions を実行する

```text
▶ Run echo "${SECRET_INFO:0:1} ${SECRET_INFO#?}"
A BCDEFG
```

:::message
**なぜ表示されるのか？**

ログに secrets の値と同じ文字列（Base64 などのよく使われるエンコードをした値を含む）が現れると、その部分が `***` に置き換わります。
この例では 1 文字目の後に空白を挟んで出力しているため、元の値と同じ文字列がログに現れず、マスクされません。
なお、公式ドキュメントでも、マスクが必ず効くとは限らないと明記されています。
:::

:::message alert

- 確認が終わったら、ワークフローから `echo` を削除し、実行ログも削除してください。
- ログのマスクは、事故を防ぐための仕組みです。上記のように簡単に回避できるため、secrets を守るには、ワークフローを変更できる人を制限することが重要です。
- 筆者の環境では、GCP の認証に使うサービスアカウント鍵（JSON 形式の複数行の値）は、この方法でもマスクされたままでした。複数行の値は行ごとにマスクされるためと考えられます。なお、公式ドキュメントでは、JSON や YAML などの構造化データを secrets に入れるとマスクされにくくなるため、推奨されていません。

:::
