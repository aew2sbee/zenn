## 🌱 はじめに

2025年にAnthropicが開発したAIコーディングエージェント`Claude Code`が登場し、エンジニアの働き方が大きく変わりました。
AIにはコーディング技術や知識では敵わなくなり、
簡単なタスクなら自然言語でお願いするだけで完了することが増えました。

自然言語で日々の業務が済むようになり、少し物足りなさを感じつつ、
今後のキャリアについて少し心配になり、赤川朗『ITエンジニアの転職学 2万人の選択から見えた、後悔しないキャリア戦略』（講談社、2025年）を読みました。

転職するつもりはないですが、キャリアの見直しに役立つと評判だったので
一読してみました。

https://www.kodansha.co.jp/book/products/0000419328

本記事では、本書で学んだ職務経歴書の書き方を8つにまとめます。

## 🌱 本書で学んだ内容(抜粋)

1. 会いたいと思ってくれる内容
2. 技術キーワードを含める
3. 多様な読み手を意識した内容
4. 能力レベルから逆算する
5. 「状況・行動と判断・成果」
6. 「なぜその判断をしたのか？」「なぜそれを除外したのか？」
7. 成果を数字で示す
8. 顧客から得た一次情報のエピソード

## 🌱 1. 会いたいと思ってくれる内容

面接や面談で直接お会いしたいと思える内容にする

```diff md
- 言われたタスクを期限内に完了させました。
+ 任されたタスクだけでなく、他のメンバーのサポートや業務改善活動にも隙間時間で取り組みました。
```

## 🌱 2. 技術キーワードを含める

「React」や「AWS」などどんな技術を使用しているのかを分かりやすくする

```diff md
- クラウド環境で開発していました。
+ AWSのCloud9を使用して開発していました。
```

※AWS Cloud9 は、2024年7月25日に新規利用の受け付けを終了しています。

## 🌱 3. 多様な読み手を意識した内容

読み手の全員がエンジニアで、同じ領域の知識を持っているとは限りません。
非エンジニアや他領域のエンジニアでも理解しやすい内容や文章を意識します。

```diff md
- Pythonのpytestライブラリで単体テストのコードを作成しました。
+ Pythonのテストライブラリの中で最も人気のあるpytestで単体テストのコードを作成しました。
```

## 🌱 4. 能力レベルから逆算する

読み手に、自分がどんな人物かをイメージさせる

- NG: どんな人かイメージできない
- OK: 自走できるエンジニアをイメージさせる

```diff md
- 開発しておりました。
+ 新規ライブラリの選定にあたり、ドキュメントの充実度やメリット/デメリットを一覧表にまとめてチームに共有し、採用するライブラリを決定しました。
```

## 🌱 5. 「状況・行動と判断・成果」

やったことリストではなく、「どんな状況で」「どんな判断をして」「どんな結果になったのか」

```diff md
- 開発しておりました。
+ ○○の状況下で△よりも□を優先すべきと判断して開発し、顧客の要望を低コストで実現できました。
```

## 🌱 6. 「なぜその判断をしたのか？」「なぜそれを除外したのか？」

自分の言葉で第三者が納得する内容の文章を書く

```diff md
- AIが言ったから
+ AIも活用しながら、公式サイトや個人の技術ブログの情報も参考にし、トータルコストを考慮して○○に決定しました。
```

## 🌱 7. 成果を数字で示す

よく言われる内容だと思いますので、さらっと解説します

```diff md
- 開発効率を大幅に改善した
+ 開発効率を30%向上させ、タスクを10営業日前倒しで完了しました。
```

## 🌱 8. 顧客から得た一次情報のエピソード

顧客の要望からどのような新機能や新サービス/機能改修が発生したのか？

```diff md
+ 利用者の大半は年齢層が高いため、デフォルトの文字サイズを16pxから18pxに変更したところ、大変見やすくなったとの声を頂きました。
```
