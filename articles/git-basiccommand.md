## 🌱 はじめに

Git コマンドのチートシートがあったら便利だと思い執筆しました。

使用頻度が高い Git コマンドは覚えましたが、使用頻度が低いコマンドは忘れやすいです。
また、チームメンバー間で**教育資料として活用したい**という思いもあります。

今後、覚えたい Git コマンドがあれば必要に応じて加筆します。

### 対象読者

- Git に関する基本用語を理解している方。
- Git コマンドを省略する方法を知りたい方。

### この記事でわかること

- うろ覚えだったコマンドを再認識できる。
- Git コマンドを省略する方法を理解できる。

## 🌱 clone コマンド

意味：リモートリポジトリをローカルに複製するコマンド。

```bash
git clone [リモートリポジトリのURL]
```

## 🌱 add コマンド

意味：作成・変更・削除したファイルをステージングエリアに追加するコマンド。

```bash
git add [ファイル名]
```

## 🌱 commit コマンド

意味：ステージングエリアの変更内容をコミットするコマンド。

```bash
git commit -m "[コミットメッセージ]"
```

## 🌱 status コマンド

意味：リポジトリの状態を確認するコマンド。

```bash
git status
```

## 🌱 log コマンド

意味：コミットの履歴を確認するコマンド。

```bash
git log
```

## 🌱 pull コマンド

意味：リモートリポジトリから最新の変更を取得してマージするコマンド。

```bash
git pull
```

## 🌱 push コマンド

意味：ローカルリポジトリの変更内容をリモートリポジトリにプッシュするコマンド。

```bash
git push
```

:::message
新しく作成したブランチを初めてプッシュする場合は、`git push -u origin [ブランチ名]`を実行する。
:::

## 🌱 branch コマンド

意味 1：ローカルに新しいブランチを作成するコマンド。

```bash
git branch [新しく作成するブランチ名]
```

意味 2：ローカルのブランチ一覧を確認するコマンド。

```bash
git branch
```

## 🌱 checkout コマンド

意味：指定したブランチに切り替えるコマンド。

```bash
git checkout [切り替え先のブランチ名]
```

Git 2.23 以降は、ブランチの切り替え専用の`git switch`でも切り替えられる。

```bash
git switch [切り替え先のブランチ名]
```

## 🌱 merge コマンド

意味：指定したブランチを現在のブランチにマージするコマンド。

```bash
git merge [取り込みたいブランチ名]
```

## 🌱 Git コマンドを省略する方法

手順：git config にエイリアスを設定すると、コマンドを短く書ける。

```bash
git config --global alias.<短縮名> <元のコマンド>
```

### サンプルコマンド

:::message
今後、`git status`を`git st`として使いたい場合は、下記のコマンドを実行する。
:::

```bash
git config --global alias.st status
```
