## Q63: リポジトリにバグレポートを提出したり、新機能を提案したりするユーザーが、どのような情報を記入すればよいかわかるように案内するには、どうすればよいでしょうか？

### 選択肢

- Issue テンプレートを作成する
- 作成した Issue にラベルを追加する
- GitHub Projects のプロジェクトを立ち上げる
- コピーしやすく、クローズされない Issue の例をリポジトリに置く
