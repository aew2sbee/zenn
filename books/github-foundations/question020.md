## Q20: GitHub Actions のワークフローはイベントによってトリガーされます。GitHub Actions がサポートする有効なイベントはどれですか？（2 つ選択してください）

### 選択肢

- ブランチにコミットがプッシュされたとき
- プルリクエストが作成されたとき
- リポジトリの設定が変更されたとき
- 依存関係に新たな脆弱性が検出されたとき
- リポジトリに新しいメンバーが追加されたとき
