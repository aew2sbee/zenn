## Q36: Enterprise Managed Users とは何ですか？

### 選択肢

- GitHub Enterprise の機能で、Microsoft Entra ID（旧 Azure AD）や Okta などの外部 ID プロバイダーからユーザーアクセスを管理できます。
- 依頼に応じて GitHub サポートが Enterprise の管理に使用する、GitHub Enterprise のサポートユーザーです。
- Enterprise 内の複数のユーザーが使用できる共有ユーザーアカウントです。
- GitHub のウェブ UI にはアクセスできず、GitHub Enterprise での自動化タスクにのみ使用するユーザーアカウントです。
