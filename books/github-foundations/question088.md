## Q88: プルリクエストを Issue にリンクする方法はどれですか？（2 つ選択してください）

### 選択肢

- プルリクエストまたは Issue のビューから手動でリンクする
- プルリクエストの説明でキーワードを使用し、Issue 番号を参照する
- プルリクエストの説明でキーワードを使用し、Issue のタイトルを参照する
- コードの変更に Issue 番号を含める
- コミットメッセージに Issue 番号を含める

### 回答欄

:::details 回答を見る
[公式ドキュメント](https://docs.github.com/ja/issues/tracking-your-work-with-issues/using-issues/linking-a-pull-request-to-an-issue)

- [x] プルリクエストまたは Issue のビューから手動でリンクする
- [x] プルリクエストの説明でキーワードを使用し、Issue 番号を参照する
- [ ] プルリクエストの説明でキーワードを使用し、Issue のタイトルを参照する
- [ ] コードの変更に Issue 番号を含める
- [ ] コミットメッセージに Issue 番号を含める（Issue 番号を含めるだけではリンクされません。なお、クローズキーワードはデフォルトブランチへのコミットメッセージでも使えます。）

:::
