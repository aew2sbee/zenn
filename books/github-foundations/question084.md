## Q84: GitHub のスラッシュコマンドとは何ですか？

### 選択肢

- プルリクエストやIssueのコメントや説明に複雑な Markdown を素早く挿入する方法です。
- GitHub Actions を自動化する方法です。
- GitHub CLI の別名です。
- プルリクエストのコード変更に含まれるフォーマットの問題を素早く修正する方法です。
