## Q35: GitHub で 2 要素認証（2FA）を有効にすべきなのは誰ですか？

### 選択肢

- すべての GitHub ユーザー
- GitHub で 2FA を使うことは誰にも推奨されない
- GitHub 組織のオーナー
- GitHub Enterprise Server ユーザー
