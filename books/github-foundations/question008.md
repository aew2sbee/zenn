## Q8: これらのワークフローのうち、GitHub Projects に組み込まれている自動化はどれですか？（2 つ選択してください）

### 選択肢

- プロジェクトのIssueやプルリクエストがクローズされると、そのステータスは Done に設定されます。
- プロジェクト内のプルリクエストがマージされたとき、ステータスが Done に設定される
- プロジェクト内の Issue やプルリクエストがオープンされると、ステータスが Done に設定されます。
- 新しいコントリビューターがリポジトリに追加されると、未割り当てのIssueがそのコントリビューターに割り当てられます。
- GitHub Actions がトリガーされると、GitHub Projects に新しいアイテムが作成されます。
