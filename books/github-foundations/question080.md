## Q80: GitHub Enterprise のデプロイオプションに関する次の記述のうち、正しいものはどれですか？（2 つ選択してください）

### 選択肢

- GitHub Enterprise Cloud は、GitHub.com の高度な機能セットです。
- GitHub Enterprise Server は、企業のインフラストラクチャ上で動作するセルフホストプラットフォームです。
- GitHub Enterprise Server は、GitHub.com 上の高度な機能セットです。
- GitHub Enterprise Cloud は、企業のクラウドインフラストラクチャ上で動作するクラウドホスティングプラットフォームです。
- GitHub Enterprise Cloud は、企業のインフラストラクチャ上で動作するセルフホストプラットフォームです。
