## 🌱 読書メモ

### 📌 VimとEmacsの大きな違いとは？
一番大きな違いは設計思想。Vimは「テキストを素早く編集するための道具」、Emacsは「何でも拡張できる作業環境」として作られている。

:::details 🤖 Claude に相談した内容
| | Vim | Emacs |
| --- | --- | --- |
| 操作方式 | モード式。ノーマルモード（移動・操作）とインサートモード（入力）を切り替える | モードレス。常に文字を入力でき、`Ctrl` や `Alt` との同時押しでコマンドを実行する |
| キー操作の考え方 | `d`（削除）と `w`（単語）を組み合わせて `dw` のように、動詞と目的語を組み合わせる | `C-x C-s`（保存）のように、修飾キー付きのショートカットを使う |
| 拡張言語 | Vim script（Neovim では Lua も使える） | Emacs Lisp。エディタ自体の大部分が Emacs Lisp で書かれており、ほぼすべての挙動を書き換えられる |
| 守備範囲 | テキスト編集に集中している | ファイル管理、タスク管理（Org mode）、Git 操作（Magit）なども Emacs の中で行える |
| 動作 | 軽量で起動が速い。多くのサーバーに `vi` が標準で入っている | Vim より重め。起動したまま常駐させて使う人が多い |

- Vim は、キーを組み合わせて、手をホームポジションから離さずに素早く編集するためのエディタ。サーバー上での作業とも相性がよい。
- Emacs は、自分の好きなように作り込んで、作業環境そのものにするためのエディタ。
- Emacs 上で Vim の操作方法を再現する Evil というパッケージもあり、両方を組み合わせて使う人もいる。

参考: https://www.vim.org/
参考: https://www.gnu.org/software/emacs/
:::

### 📌 LSPとは？
LSP（Language Server Protocol）は、補完や定義ジャンプなど、プログラミング言語に対する編集支援機能を、エディタと「言語サーバー」の間でやり取りするための共通の取り決め（プロトコル）。LSP は編集支援機能そのものではなく、その機能を受け渡す方法を決めたもの。

:::details 🤖 Claude に相談した内容
LSP が登場する前は、エディタごとに言語ごとの編集支援機能を作る必要があった。エディタが M 個、言語が N 個あれば、M × N 通りの実装が必要になる。

LSP では役割を2つに分ける。

| | 言語サーバー | エディタ（LSPクライアント） |
| --- | --- | --- |
| 役割 | コードを解析して、補完候補やエラーなどを返す | 言語サーバーに問い合わせて、結果を画面に表示する |
| 具体例 | typescript-language-server（TypeScript）、Pyright（Python） | VS Code、Neovim（標準搭載）、Emacs（Eglot を標準搭載） |

- 言語ごとに言語サーバーを1つ作れば、LSP に対応したどのエディタでも同じ編集支援機能を使える。必要な実装は M + N 通りで済む。
- LSP でやり取りできる主な機能は、コード補完、定義へのジャンプ、参照箇所の検索、エラーや警告の表示、名前の一括変更など。
- Microsoft が VS Code のために作り、2016年に公開した。現在は Vim や Emacs でも使えるため、どのエディタを選んでも VS Code に近い編集支援機能を受けられる。

参考: https://microsoft.github.io/language-server-protocol/
:::

### 📌 Vimの始め方
Git for Windows の Git Bash や macOS には最初から Vim が含まれているため、インストールしなくてもすぐに始められる。まずはターミナルで次のコマンドを実行して、Vim が入っているかを確認する。

```bash
vim --version
```

:::details 🤖 Claude に相談した内容
- バージョン情報が表示されれば、そのまま使える。表示されない場合は、Vim の公式サイトからインストーラーを入手するか、Windows なら `winget install vim.vim` でインストールする。
- Git Bash や macOS に含まれている Vim も、ソースコードは GitHub の [vim/vim](https://github.com/vim/vim)（Vim 本家のリポジトリ）と同じもの。Git Bash は MSYS2、macOS は Apple がそれぞれビルドして同梱している。
- 配布元によって、バージョンが本家の最新より少し古かったり、有効になっている機能（Python 連携や GUI など）が違ったりする。ただし、基本操作を覚える分には違いはない。
- Vim 本体を入れずに Vim の操作だけを試したい場合は、VS Code の拡張機能「Vim」（VSCodeVim）を使う方法もある。

参考: https://www.vim.org/download.php
:::

### 📌 vimtutor ja で日本語のチュートリアルを始められる
ターミナルで `vimtutor ja` を実行すると、Vim に付属している日本語のチュートリアルが開く。

```bash
vimtutor ja
```

:::details 🤖 Claude に相談した内容
- `vimtutor` は Vim に付属しているコマンドで、Vim をインストールすると一緒に使えるようになる。引数の `ja` は日本語版を開く指定で、省略すると、環境の言語設定に合った版（対応する版がなければ英語版）が開く。
- チュートリアルは、カーソル移動、削除、コピー＆ペースト、検索、保存などの基本操作を、実際に手を動かしながら学ぶ構成になっている。所要時間は25〜30分程度。
- 開かれるのはチュートリアルファイルのコピーなので、自由に編集しても元のファイルは変わらない。
- 途中で終了したいときは、`Esc` を押してから `:q!` と入力して `Enter` を押す。

Git for Windows に付属する Vim 9.1 にも、`vimtutor` コマンドと日本語版のチュートリアルファイル（`tutor.ja.utf-8`）が含まれている。

参考: https://vimhelp.org/usr_01.txt.html#vimtutor
:::
