## Q124: GitHub ディスカッションで実行できるアクションはどれですか？（3 つ選択してください）

### 選択肢

- ディスカッションをピン留めする
- 別のリポジトリのディスカッションに転送する（管理者権限がある場合）
- ディスカッションを秘密の gist に変換する
- issue に変換する
- 既存のプルリクエストにマージする
