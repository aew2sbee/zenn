## Q104: GitHub のディスカッションから Issue を作成し、その Issue がクローズされたり、# 番号で参照されたりした場合、ディスカッションは変更されますか？

### 選択肢

- No
- Yes

### 回答欄

:::details 回答を見る
[公式ドキュメント](https://docs.github.com/ja/issues/tracking-your-work-with-issues/creating-an-issue#creating-an-issue-from-discussion)

- [x] No（ディスカッションから Issue を作成すると、ディスカッションにリンクされた新しい Issue が作成され、Issue の情報が事前に入力されます。両者はリンクでつながるだけで、それ以上の関係はありません。）
- [ ] Yes

:::
