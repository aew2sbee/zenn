## Q119: Organization のリポジトリで、トリアージロールのユーザーが実行できる操作はどれですか？

### 選択肢

- コミットをプッシュする
- issues とプルリクエストを管理する
- リポジトリの削除
- リポジトリの設定を変更する
- 新規リポジトリの作成

### 回答欄

:::details 回答を見る
[公式ドキュメント](https://docs.github.com/ja/organizations/managing-user-access-to-your-organizations-repositories/managing-repository-roles/repository-roles-for-an-organization)

- [ ] コミットをプッシュする
- [x] issues とプルリクエストを管理する（トリアージロールは、書き込み権限なしで Issue とプルリクエストを管理できます。翻訳元の問題文は正解と対応していなかったため、正解に合わせて問題文を変更しています。）
- [ ] リポジトリの削除
- [ ] リポジトリの設定を変更する
- [ ] 新規リポジトリの作成
