## Q109: GitHub でサポートされている2 要素認証や多要素認証にはどのようなものがありますか？（5 つ選択してください）

### 選択肢

- パスキー
- テキストメッセージ
- 電話（音声通話）
- メール
- セキュリティキー
- GitHub Mobile
- 時間ベースのワンタイムパスワード (TOTP)

### 回答欄

:::details 回答を見る
[公式ドキュメント](https://docs.github.com/ja/authentication/securing-your-account-with-two-factor-authentication-2fa/accessing-github-using-two-factor-authentication)

- [x] パスキー
- [x] テキストメッセージ
- [ ] 電話（音声通話）（テキストメッセージは一部の国でサポートされていますが、電話はサポートされていません。）
- [ ] メール
- [x] セキュリティキー
- [x] GitHub Mobile
- [x] 時間ベースのワンタイムパスワード (TOTP)

:::
