## Q145: GitHub リポジトリにファイルを追加するために必要な条件はどれですか？

### 選択肢

- リポジトリのオーナーであること。
- リポジトリへの読み取りアクセス権を持っていること。
- リポジトリへの書き込みアクセス権を持っていること。
