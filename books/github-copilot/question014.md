## Q14: GitHub Copilot を始める最も簡単な方法は何ですか？

### 選択肢

- GitHub Copilot を使用する前に、GitHub サポートにアクセスをリクエストし、承認を待つ
- Copilot のウェブサイトを使用し、提案を求める際にコードを貼り付ける
- Visual Studio Code など、使っている環境に Copilot 拡張機能をインストールする
- 新しいパブリックリポジトリを作成し、Copilot にコードをスキャンして提案させる
