## Q25: GitHub Copilot の回答に対して行われる後処理のチェックはどれですか？

### 選択肢

- 構文の検証とコードの書式チェックのみ
- 性能ベンチマークとメモリ使用量の最適化
- 有害な言語、関連性、コード品質（セキュリティの脆弱性を含む）、一意の識別子（unique identifiers）、オプションの公開コード照合
- コンパイルエラーと実行時例外のチェックのみ
