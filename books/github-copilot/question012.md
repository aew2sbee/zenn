## Q12: GitHub Copilot は、コンテンツの除外で無視されるファイルのセマンティック情報を使用できますか？

### 選択肢

- はい、IDE から間接的に情報が提供される場合は使用できる
- いいえ、除外されたファイルからの情報はすべて無視される

### 回答欄

:::details 回答を見る
[公式ドキュメント](https://docs.github.com/ja/copilot/concepts/context/content-exclusion#limitations-of-content-exclusion)

- [x] はい、IDE から間接的に情報が提供される場合は使用できる
- [ ] いいえ、除外されたファイルからの情報はすべて無視される（IDE から間接的に情報が提供されている場合、Copilot は除外されたファイルのセマンティック情報を使用することがあります。例えば、コードで使用されるシンボルの型情報、ホバー時に表示される定義、ビルド構成などのプロジェクト全般のプロパティです。）

:::
