## Q20: GitHub Copilot を使って開発者のワークフローを強化する利点は、次のうちどれですか？

### 選択肢

- すべてのプロジェクトでコードレビューを完全に代替する
- 開発者の生産性を高めるために、コードスニペットを提案する
- 人間の承認なしにプルリクエストを自動的にマージする
- 単一のプログラミング言語で書かれたソフトウェアにのみ対応する
