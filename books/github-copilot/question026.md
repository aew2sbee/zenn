## Q26: GitHub Copilot はどの要素をコンテキストとして使用できますか？

### 選択肢

- 編集中のコード行だけで、周囲のコンテキストは使わない
- インターネット上の外部ドキュメントだけ
- プロジェクトの README ファイルだけ
- 現在のファイルの内容、隣接ファイル、リポジトリの URL、ファイルパス、以前のチャットでのやり取り
