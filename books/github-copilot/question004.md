## Q4: GitHub CLI に GitHub Copilot 拡張機能をインストールするには、どのコマンドを使用しますか？

### 選択肢

- `gh extension install github/gh-copilot`
- `gh copilot install`
- `gh copilot setup`
- `gh extension add copilot`
