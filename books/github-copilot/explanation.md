## はじめに

GitHub Copilot の認定試験を受験するにあたり、日本語の問題集が見つからなかったため自作しました。
同じ試験の受験を目指す方の役に立てば幸いです。

各章は「問題」「選択肢」「回答欄」で構成しています。回答欄の「回答を見る」を開くと、正解と根拠となる公式ドキュメントへのリンクが表示されます。

## 注意事項

:::message alert

### 1. 日本語訳について

`DeepL`を使用して翻訳しました。不自然な日本語が含まれている可能性があります。

### 2. 回答の誤りについて

基本的にコピペで作成しました。
しかし、コピペミスがある可能性があります。
誤りがある場合は修正の PR をいただけると助かります。

### 3. 問題の追加について

現在は Q1〜Q26 を収録しています。問題は随時追加していきます。

### 4. 問題の内容について

翻訳元の問題集が MIT License だった時点の内容を翻訳しています。その後に提供を終了した機能を扱う問題には、回答欄に注記を付けています。

:::
