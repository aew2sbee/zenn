## Q22: GitHub Copilot のスラッシュコマンド `/tests` の主な目的は何ですか？

### 選択肢

- 新しいテストを生成せずに、プロジェクト内の既存の単体テストをすべて実行する
- 新しいテストを作成せずに、既存のテストファイルの構文検証のみを行う
- 現在開いているファイルの単体テストを生成する。既存のテストファイルがあれば、そのコンテキストも使う
- 既存のテストファイルをすべて完全に削除し、最初からやり直す
