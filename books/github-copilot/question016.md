## Q16: GitHub Copilot の説明として最も適切なものはどれですか？

### 選択肢

- コードベースの変更を追跡・管理するバージョン管理システム
- デバッグやエラーチェック機能を備えたコードエディタ
- コードを提案し、コードスニペットを補完することで開発者を支援する AI コーディングアシスタント
- コードを自動的にテストし、本番環境にデプロイするツール
