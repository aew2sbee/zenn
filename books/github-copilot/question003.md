## Q3: GitHub Copilot はどの IDE をサポートしていますか？（2 つ選択してください）

### 選択肢

- Visual Studio Code, Xcode, Vim/NeoVim
- Azure Data Studio, Visual Studio, IntelliJ IDEA
- Visual Studio, NetBeans, Eclipse
- Visual Studio, BlueJ, NetBeans

### 回答欄

:::details 回答を見る
[公式ドキュメント](https://docs.github.com/ja/copilot/how-tos/get-code-suggestions/get-ide-code-suggestions)

- [x] Visual Studio Code, Xcode, Vim/NeoVim
- [x] Azure Data Studio, Visual Studio, IntelliJ IDEA（翻訳元の問題作成時点の正解です。現在の公式ドキュメントの対応 IDE に Azure Data Studio は含まれていません。）
- [ ] Visual Studio, NetBeans, Eclipse（NetBeans はサポートされていません。）
- [ ] Visual Studio, BlueJ, NetBeans

:::
